# Приёмка человеком

Для того, кто не участвовал в разработке. Идти по порядку, отмечать `[x]`, у каждого
пункта — что должно получиться. Не получилось — записать внизу: пункт, устройство,
что видно, скриншот.

Перед началом: адрес витрины, адрес кабинета (`…/cabinet.html`), логин и пароль
продавца, телефон, ноутбук. Автоматическая приёмка (`npm run smoke`) уже прошла.

## 1. Покупатель с телефона

- [ ] Открыть витрину по ссылке. Сверху название и знак магазина, цвета магазина, без мигания чужих цветов.
- [ ] Категории листаются пальцем вбок, выбор категории оставляет только её товары.
- [ ] Сортировка «Сначала дешевле» ставит дешёвые товары первыми.
- [ ] У карточек фото или крупный значок-замена, цена, скидка (если есть), «В наличии» или «Осталось N шт.».
- [ ] Нажать на товар — открывается отдельный экран товара на весь экран, адрес меняется на `?id=…`.
- [ ] Фото листаются пальцем, точки под фото показывают, какое открыто.
- [ ] Есть описание; где заполнено — состав, характеристики, особенности.
- [ ] Кнопка «В корзину» внизу экрана всегда видна, не закрывает текст страницы.
- [ ] Кнопка «назад» телефона возвращает в каталог на то же место прокрутки.
- [ ] Скопировать адрес товара, открыть в новой вкладке — открывается тот же товар.
- [ ] Открыть набор: список «В наборе», нажатие на компонент открывает его экран.
- [ ] Добавить товар: всплывает «Добавлено в корзину», на значке корзины число.
- [ ] Нажать «+» больше, чем есть в наличии, — «Больше нет в наличии», число не растёт.
- [ ] Корзина открывается на весь экран; «назад» телефона её закрывает.
- [ ] В корзине «−» и «+» меняют количество и сумму; подсказка «Ещё N шт. — и скидка» сбывается строкой скидки.
- [ ] Перезагрузить страницу — корзина на месте.
- [ ] «Оформить заказ» → поля с подписями. Отправить с телефоном `12-34` — подсказка под полем.
- [ ] Под кнопкой — ссылки на оферту и обработку персональных данных, они открываются.
- [ ] Заполнить имя и телефон, подтвердить — «Заказ создан — № …», корзина пустая.
- [ ] Внизу страницы ссылки на оферту, персональные данные, доставку и возврат.

## 2. Продавец в кабинете (ноутбук)

- [ ] Открыть кабинет: вместо заказов — форма входа.
- [ ] Неверный пароль — «Неверный логин или пароль», без подробностей.
- [ ] Верный вход: вверху логин, видна очередь заказов со сводкой.
- [ ] Заказ из раздела 1 виден: имя, телефон, состав, сумма, статус «Новый».
- [ ] «В сборку» → «Собирается», «Отгрузить» → «Доставляется».
- [ ] Оформить на витрине ещё один заказ, в кабинете «Отменить» — статус «Отменён».
- [ ] На витрине у товара из отменённого заказа наличие вернулось.
- [ ] Заказ с набором: строка набора и под ней «списано со склада» по компонентам.
- [ ] «Импорт каталога» → выбрать файл → «Проверить»: сводка, новые и изменённые позиции, ошибки по строкам.
- [ ] Если в файле есть остаток — отдельный жёлтый блок «Перезапишется склад».
- [ ] «Применить» → «Импорт выполнен»; на витрине изменения видны после обновления.
- [ ] «Площадка»: пометка «сухой прогон», «Что уйдёт» показывает цены и остатки, наборов и склада площадки в остатках нет.
- [ ] После заказа из раздела 1 через несколько секунд в «Журнале синхронизации» появляется строка «остатки · заказ».
- [ ] «Сверить с площадкой» пока отвечает «Данных площадки ещё не было», а не «расхождений нет».
- [ ] Заказы площадки (когда появятся): метка «Маркетплейс», под номером — «Ozon · FBS/FBO · отправление»;
      не хватило остатка — красная строка «проблема», фильтр «Требуют внимания» и предупреждение сверху.
- [ ] «Выйти» → снова форма входа. Перезагрузка страницы кабинета тоже требует входа.

## 3. Три ширины

Телефон (или окно шириной около 380 px), планшет (около 768), ноутбук (1280 и шире).

- [ ] На всех трёх нет прокрутки вбок, ничего не обрезано по краю.
- [ ] Каталог: 2 колонки на телефоне, 3 на планшете, 4 на ноутбуке.
- [ ] Экран товара на ноутбуке: фото слева, описание справа, миниатюры под фото.
- [ ] Корзина: на телефоне на весь экран, на планшете и ноутбуке — панель справа.
- [ ] Все кнопки нажимаются пальцем с первого раза, не нужно целиться.

## 4. Состояния

- [ ] Адрес `?id=нет-такого` — «Такого товара нет» и кнопка «Перейти в каталог».
- [ ] Выключить интернет и обновить витрину — «Не удалось загрузить витрину» и «Повторить»;
      включить интернет, нажать «Повторить» — каталог на месте.
- [ ] Товар, которого нет в наличии, — «Нет в наличии», кнопка покупки неактивна.
- [ ] Пока грузится — серые заготовки карточек, а не белый экран.
- [ ] Нигде не видно технического текста ошибки (английских слов, кода, «undefined»).

## 5. Юридическое и мессенджеры

- [ ] Оферта, персональные данные, доставка и возврат открываются, реквизиты продавца верные.
- [ ] Незаполненные реквизиты помечены «не указано» — список отдать продавцу.
- [ ] Плашка «Черновик: требует проверки юристом» — до запуска продаж тексты пишет юрист.
- [ ] Отправить ссылку на витрину в Telegram и WhatsApp — карточка с названием, описанием, картинкой.
