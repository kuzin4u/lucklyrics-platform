# Профили экземпляров

Читать, когда заводите второго продавца, выключаете площадку или проверяете,
что различие экземпляров осталось в конфигурации, а не расползлось по коду.

## Что такое профиль

Профиль — конфиг бренда целиком: `config/brand.json` активного экземпляра,
`config/brand.<slug>.json` — остальные (они же доступны предпросмотром `?preview=<slug>`
и как `BRAND_CONFIG` при запуске). Код у всех один.

- `config/brand.example.json` — образец: площадка включена, буфер 2, каналы витрина,
  площадка, помощник.
- `config/brand.no-marketplace.json` — «Своя лавка»: свой `instance.id`, название, цвет
  и типографика, свои ступени скидки и пределы помощника; площадка выключена, канал
  площадки отключён, страховой запас 0, исполнение только со своего склада, каналы
  витрина, помощник, бот. Это другой магазин, а не урезанный.

## Правило

**В ядре нет условий «если площадка выключена».** Остаток, каталог, заказы, платежи,
импорт, помощник, вход и хранилище про площадку не знают и её модули не подключают;
`bufferFor` при нуле — та же функция, а не обход. Различие живёт в конфигурации и в
`api/lib/sync.js` с `api/lib/marketplace/`. Проверяется `tests/unit/profiles.test.js`
(поиском по `api/lib`, как тест про бренд в коде).

При выключенной площадке: `GET /api/sync/log` и `GET /api/sync/diff` отвечают 200
с `disabled: true` и объяснением (`status: "DISABLED"` у сверки), `POST /api/sync/run` —
`disabled: true`; в журнале движений остатка записей о синхронизации нет, намерений
у клиента площадки тоже. В кабинете экран «Площадка» показывает состояние «выключена»
и не предлагает действий. `GET /api/health` в поле `sync` отдаёт `off`.

## Проверка двух профилей

- `tests/profiles/probe.js` — один сценарий (импорт, набор, заказ, списание, отмена,
  возврат, синхронизация, помощник, вход) на профиле из `BRAND_CONFIG`; печатает итог JSON.
  Тест сравнивает два запуска: общая часть совпадает, различия — только настроечные.
- `npm run smoke` работает на обоих. Шаги площадки при её отсутствии не падают, а
  помечаются пропущенными с причиной (`·`) — пропуск виден в отчёте и в коде выхода
  не участвует. Запуск: `BRAND_CONFIG=config/brand.no-marketplace.json npm start`,
  затем `npm run smoke http://localhost:3000`.
