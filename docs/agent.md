# AI-помощник витрины

Читать, когда меняете помощника, его промпт, лимиты, базу знаний или разбираете
его журнал и расход.

## Устройство

- `api/lib/agent.js` — единственная точка работы с моделью. Ключ — `MODEL_API_KEY`
  из окружения; в публичный конфиг уходит только `agent.enabled`, ключ и причины — нет.
- Вызов — прямой запрос к Messages API (`x-api-key`, `anthropic-version: 2023-06-01`),
  без SDK: он стал бы первой зависимостью. `MODEL_API_URL` — свой прокси.
- Модель — `agent.model` в конфиге бренда (выбор продавца). Ответ — структурированный:
  `output_config.format` со схемой `{reply, items: [{id, qty}]}`.
- Промпт: правила, каталог (артикул, название, цена, категория, вес, состав набора,
  описание) и раздел «Факты» `config/knowledge.md` — кэшируется; строка «нет в наличии»
  идёт после метки кэша. Раздел «Политика» в промпт не попадает никогда.

## Границы — кодом

- Позиции из ответа модели проверяются: нет в каталоге — отброшена, и ответ заменяется
  нейтральным (текст мог описывать выдуманное); нет в наличии — отброшена с пометкой;
  количество урезается до остатка. Название и цена — из каталога, сумма — `catalog.quote`.
- Доставка, возврат, оплата, сроки (кроме срока годности и хранения) — готовый ответ
  со ссылками на юридические страницы, модель не спрашивается. Если модель сама заговорила
  об этом — её текст заменяется готовым.
- Корзина — та же, что у каталога: «Положить в корзину» складывает состав, не больше остатка.
  Заказ после этого уходит с `agent.dialogId` — «с участием помощника»; канал — витрина.

## Лимиты и расход

Из конфига бренда: `agent.maxMessagesPerDialog` (15), `agent.maxDialogsPerVisitorPerDay` (5),
`agent.dailyBudgetUsd` — дневной потолок, $. **Без потолка помощник не включается.**
Сообщение засчитывается до вызова модели — одновременные запросы предел не обходят.
Посетитель — случайный идентификатор в браузере; запасной лимит по адресу — вчетверо
больше, адрес хранится хешем с солью. Потолок исчерпан — кнопка на витрине скрывается,
сообщение — «на сегодня отдыхает», витрина и заказы работают. День — по часовому поясу
`agent.timezone` (по умолчанию Москва).

Расход — по `usage` ответа и ценам модели в `agent.js` (вход, выход, запись и чтение кэша).

## Журнал и кабинет

Запись `agent` в хранилище: каждый ответ — запрос, ответ, предложенное, отброшенное
с причиной, готовый ли ответ, расход; хранятся последние 500 диалогов, дни — два месяца.
`POST /api/agent/message` — без входа; `GET /api/agent/stats` — за входом: диалоги
за день и месяц, заказы с участием помощника и их средний чек, расход, последние диалоги.
В кабинете — экран «Помощник».

## Проверка с реальным ключом

`MODEL_API_KEY=… npm start` (конфиг бренда с тремя числами), витрина — кнопка «Подобрать».
В тестах модель не вызывается: подставляется поддельный ответчик.
