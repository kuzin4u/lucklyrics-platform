# Импорт каталога

Читать, когда меняете импорт, добавляете колонку или разбираете отчёт импорта.

## Маршрут

`POST /api/catalog/import` за `cabinet()`. Тело — сам файл, CSV или JSON (список
или `{items: [...]}`); формат — по `?format=`, `Content-Type` или содержимому.
`?dryRun=1` — предпросмотр: тот же расчёт, ничего не пишет. Кодировка: UTF-8,
иначе Windows-1251 — так сохраняет Excel. В кабинете — экран «Импорт каталога».

## Колонки

- По названиям, русским и английским, как в коде пекарни: регистр и пробелы по
  краям не важны, для поля берётся первое совпавшее название из `COLUMNS`.
  Новое название колонки добавляется в `COLUMNS`, а не в разбор.
- Незнакомая колонка не теряется: сохраняется у позиции полем `attrs`
  и показывается в отчёте как новое поле.
- Пустая ячейка значение не меняет. Список через `|` — особенности, фотографии.

## Правила

- Идемпотентность по артикулу: повтор обновляет, а не плодит дубли; одинаковый
  файл — ноль записей.
- Ошибки — списком по строкам («строка 7: цена не число»), разбор не прерывается,
  строки с ошибками пропускаются, остальные применяются. Негодное значение —
  ошибка строки, а не молчаливый 0.
- Новой позиции нужны название и цена.

## Остаток в файле

Остаток — не описание товара. Колонки остатка идут отдельным списком `stock`
в отчёте и отдельным блоком «Перезапишется склад» в предпросмотре. Нет колонки
или пустая ячейка — остаток не трогается вовсе. Пишется через `stock.setMany`
с причиной `import` и продавцом из токена. Сначала пишется каталог, потом склад.

## Страховой запас и наборы

- «Страховой запас» пишет `buffer` позиции.
- «Состав набора» (`SKU-001×2|SKU-003×1`, множитель `×` или `*`, без него — 1)
  делает строку набором. Просто «Состав» — ингредиенты (`composition`), текст
  для карточки: у продавцов еды так называется эта колонка.
- «Артикул площадки» (`offer_id`) — под ним уходят цены и остатки и по нему приходят заказы;
  не задан — идентификатор позиции. Два одинаковых — ошибка строки.
- «Изображения» / «Фото» — внешние адреса через `|` или перевод строки
  (см. `docs/storefront.md`).
- Состав проверяется вторым проходом: компонент — из каталога или из этого же
  файла, порядок строк не важен. Ошибки строки: набор в наборе, ссылка на себя,
  несуществующий компонент или компонент из строки с ошибкой, остаток или
  страховой запас у набора, превращение существующего товара в набор.
