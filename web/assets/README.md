# Ассеты экземпляра

Файлы оформления конкретного продавца: `logo.png`, `favicon.png`, `preview.png`
(картинка для превью в мессенджерах). Медиа товаров сюда не кладём — они живут
во внешнем хранилище.

Если логотипа нет, витрина рисует текстовый знак: первая буква названия на
акцентном фоне. Это осознанный запасной вариант, а не ошибка — сайт можно
поднять и показать, не дожидаясь файлов от дизайнера.
